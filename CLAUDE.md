## Project layout

The Next.js app is **not at the repo root** — it lives one directory down at `devstash/devstash/`
(this file's directory). The git repository, `package.json`, and `node_modules` are all here.
Run every command from this directory, not the outer `devstash/` folder (which only holds an empty
placeholder `package-lock.json`).

## Commands

```bash
npm run dev     # start dev server (http://localhost:3000)
npm run build   # production build
npm run start   # serve the production build
npm run lint    # eslint (flat config, eslint-config-next core-web-vitals + typescript)
```

There is no test runner configured yet.

## Stack

- **Next.js 16** (App Router) + **React 19** — see `@AGENTS.md`: this Next major has breaking changes
  from older versions; consult `node_modules/next/dist/docs/` before writing framework code.
- **Tailwind CSS v4** — configured entirely through `@import "tailwindcss"` in
  `src/app/globals.css` and the `@tailwindcss/postcss` plugin. There is no `tailwind.config` file;
  customize via CSS `@theme` blocks in `globals.css`.
- **TypeScript strict**, `noEmit`. Import alias `@/*` maps to `src/*`.
- Route-aware global types such as `LayoutProps<"/">` and `PageProps<...>` are generated by Next into
  `.next/types` — run `npm run dev` or `npm run build` if the type checker can't find them.
